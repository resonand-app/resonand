Where the audio goes, before it goes. §3.4's disclosure, and the only implementation of the product's second principle.

```jsx
<EgressNotice destination={destination} />                       {/* a panel, or a dialog */}
<EgressNotice destination={destination} placement="retry" action={<Button variant="secondary">Retry</Button>} />
```

`destination` is `GET /transcription/destination` verbatim — readable by any authenticated caller, because a disclosure only administrators can read is not one. **Two registers, because there are two genuinely different cases**: a `faster-whisper` on the same machine is calm and quiet, an external provider is factual and takes the accent. Neither is a warning banner — no red, no exclamation mark. The third case is nothing configured, which says so rather than offering a retry for something that cannot be attempted. Wherever a transcription can be requested, this is on the screen first.
