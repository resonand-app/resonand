A recording in the card view of a library. Taller waveform than the library card (52px) because the recording itself is the subject here.

```jsx
<RecordingCard name="The house on Carrer Nou" meta="48:12 · 12 Mar 2026" state="done" tags={["memòria","català"]} peaks={rec.peaks} />
```

Use the dense RecordingRow instead once a library passes a few dozen recordings.
