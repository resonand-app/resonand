The signature element. Amplitude sampled into rounded bars with fully rounded caps; minimum bar height equals bar width, so a silent passage stays a row of dots rather than disappearing.

```jsx
<Waveform peaks={rec.peaks} height={38} />
<Waveform peaks={rec.peaks} height={34} played={0.42} playhead advance={0.0004} playedAt={at} />
<Waveform pending height={20} />
<Waveform peaks={rec.peaks} height={52} lit />
```

Never draw a filled envelope, a stroked contour, or a bar chart with square caps. Never invent a shape for a recording whose peaks job has not run — use `pending`, which is also what an empty `peaks` array draws. `played` is an anchor and not an instruction: give it `advance` — how much of the recording a second of playback covers — and the drawing carries the position forward itself on every frame, instead of stepping four times a second when the element reports in. `playedAt` says when the anchor was true, since a position reported at 20 ms to 250 ms intervals is already a few milliseconds old by the time it arrives. Pass `onSeek` to make it a control: the drawing takes a press, follows the pointer for as long as the button is held, and reports the fraction when it is let go -- a click is just the short version of that. Wiring it to clicks alone gave nothing back for the whole of a drag, which reads as a control that has stopped responding. It is a `slider`, so the arrow keys, `Home` and `End` seek too, and a surface that shows the position as a number beside the drawing should take `onPreview` as well: during a drag the playhead is where the pointer is and a readout still showing the sound would be a second, contradictory position. `lit` is the other thing entirely: the whole shape in `--wave` instead of `--wave-dim`, and nothing that moves. It is how a surface says "this is the one playing" without drawing a second playhead -- a card uses it, because the player at the foot of the shell is the one place playback has a position. The mark in `Logo` shares this geometry, so logo and data read as the same object.
