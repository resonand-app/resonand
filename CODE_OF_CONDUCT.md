# Code of conduct

This project holds recordings of people's families, their interviews and their thinking out loud.
The people who end up here are often not developers, and several of them will arrive because
somebody else set an instance up for them. That is the standard this page is set to.

## What is expected

Take the other person's report at face value. Say what you mean plainly, including when you
disagree — disagreement about the premises is explicitly invited in
[`CONTRIBUTING.md`](CONTRIBUTING.md) and is not a conduct problem. Assume the person on the other
side has less context than you rather than less sense.

## What is not

Harassment, in the ordinary meaning of the word: personal attacks, sustained hostility, sexualised
attention, and any attention paid to somebody's identity rather than to what they wrote. Publishing
somebody's private information. Deliberately wasting a maintainer's time.

None of that gets a warning system, because a project this size cannot run one.

## Reporting

**One person maintains this.** There is no committee, and pretending otherwise would be the kind of
furniture this project tries not to build.

- If somebody's behaviour in an issue or a pull request is the problem, say so in that thread if you
  are comfortable doing it, or contact the maintainer directly through their GitHub profile.
- If the behaviour is GitHub-wide rather than about this repository, GitHub's own abuse reporting
  reaches people who can act on it and I cannot.

I will read it, and I will say what I am going to do. The available responses are editing or
deleting a comment, locking a thread, and blocking an account — that is the whole toolbox a
repository owner has, and I would rather name it than imply a process that does not exist.

## Scope

Issues, pull requests, discussions and commit messages in this repository. Not somebody's conduct
elsewhere, which is not mine to police.

---

This is deliberately not the Contributor Covenant. That document assumes an enforcement body, a
reporting address and a graduated response, and this project has none of those; a code of conduct
that describes a process nobody is going to follow is worse than a short one that is true.
